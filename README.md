## Overview

Squeak Through removes the collision boxes from pipes, electric poles, trees, and other passable-looking objects in Factorio, letting players walk through them naturally. This eliminates the frustration of being blocked by a single pipe crossing a walkway and makes dense factory interiors navigable without building dedicated corridors.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Squeak Through** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Pipe Passthrough** | Walk through pipe runs without collision, eliminating factory maze navigation |
| **Pole Passthrough** | Electric poles no longer block player movement in crowded factory areas |
| **Tree Passthrough** | Natural tree tiles become passable for forest exploration and paths |
| **Configurable Entities** | Choose exactly which entity types should have passthrough enabled |
